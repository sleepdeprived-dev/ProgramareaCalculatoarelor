# 💻 Programarea Calculatoarelor

📚 Repository cu exercițiile rezolvate la disciplina
**Programarea Calculatoarelor** din cadrul programului **IAAEA – CSIE, ASE**.

## 📂 Structură

Problemele sunt organizate pe seminare, fiecare conținând problemele de la seminarul respectiv:

- 📁 `seminar-01/`
- 📁 `seminar-02/`
- 📁 `seminar-03/`
...

## 🎯 Scop

Repository-ul este folosit pentru:

- 💾 păstrarea soluțiilor realizate la seminar;
- 📈 urmărirea progresului pe parcursul semestrului;
- 🧠 exersarea programării și a rezolvării problemelor.
